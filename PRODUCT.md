# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static Markdown documentation rendered by Docsify and deployable to Cloudflare Pages without a build step.

## Users

Frontend developers and coding-agent users evaluating or using AntiSlop to catch common AI-generated design patterns and frontend quality issues.

## Product Purpose

AntiSlop detects common AI-generated website patterns. Its documentation helps users install the scanner, run it, and understand each rule.

## Capabilities and Constraints

- The documentation must remain lightweight and run locally without adding project dependencies.
- Existing rule Markdown and screenshots are the source material.
- Cloudflare Pages is the intended host.

## Brand Commitments

- Product name: AntiSlop.
- Direct, technical language.
- Dark technical documentation interface.

## Evidence on Hand

- Scanner usage and installation instructions in `README.md`.
- 44 documented rules and their screenshots in `docs/rules/`.

## Product Principles

- Put working commands before explanation.
- Make every rule easy to find.
- Keep documentation infrastructure simpler than the product it documents.
