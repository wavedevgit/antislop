# Design

## Documentation surface

- Mode: Read.
- Ink-black background with charcoal panels, bright blue signal color, and off-white text.
- System sans-serif for interface labels and prose; system monospace only for code, commands, and scan output.
- Fixed 56px top bar with a scan-frame mark and source link.
- 264px rule sidebar with grouped navigation and a persistent search field.
- Content measure of 840px with hairline section rules and generous vertical spacing.
- Home opens with the product claim, a real scanner finding in a code block, and two actions.
- Rule pages keep screenshots full-width inside a hairline frame and use compact, borderless tables.
- Mobile collapses the sidebar behind a 56px toggle and stacks command rows.
