# DeepSeek experiment

Model: **DeepSeek V4.1 Flash Free** (openCode)

Five standalone HTML pages, one per topic. Each is self-contained: inline CSS, inline SVG, no external fonts, scripts, or images. The detector inventory was read only to understand the project; the designs were not steered by it.

| File | Topic | Design direction |
| --- | --- | --- |
| `01-library.html` | Mercer Street Public Library | Editorial print: warm paper, serif masthead, catalogue card, book covers, events table |
| `02-bakery.html` | Lark Street Bakery | Artisanal print: dough palette, arched hero, line-art loaf, rotating badge, 36-hour process |
| `03-marine-lab.html` | Halcyon Marine Research Station | Dark scientific: depth-profile illustration, live buoy data, chart, expedition schedule |
| `04-bike-repair.html` | Rueben's Cycle Works | Workshop industrial: hi-vis yellow, condensed display type, technical bike drawing, job-ticket form |
| `05-theater.html` | The Lantern Theatre | Poster drama: high-contrast serif, spotlight hero, five season posters, cream auditorium section |

Open any file directly in a browser. Viewport-friendly down to ~360 px; no build step.
