# mimo experiment pages

Five standalone HTML pages (inline CSS + inline SVG, no external assets),
generated by the model **mimo-v2.6-flash-free** as a control set for the
anti-slop detector. Design choices were made freely, without consulting or
avoiding the rule set.

| File | Topic |
|------|-------|
| `01-garden.html` | Urban gardening club (Root & Rooter) |
| `02-observatory.html` | Astronomy observatory (Fenwick Ridge) |
| `03-hotel.html` | Small coastal hotel (Hotel Zephyr) |
| `04-radio.html` | Community radio station (WCRK 91.3) |
| `05-ceramics.html` | Ceramics studio (Slip & Stone) |
