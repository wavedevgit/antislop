# Aurora glow background

![Aurora glow background example](./assets/no-aurora-backgrounds.png)

AI-generated hero sections often use oversized blurred color blobs or layered radial gradients as atmospheric decoration.

## How it works

Looks for oversized blurred color blobs and layered radial gradients used as atmospheric backgrounds.

## How to fix

Remove decorative blurred blobs and layered radial gradients. Use a solid surface, restrained image, or content-led composition instead.

## Common false positives

Data visualizations, lighting simulations, and artwork may use blurred color or radial gradients as meaningful content.
