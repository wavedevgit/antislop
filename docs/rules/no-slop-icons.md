# Slop icons

![Slop icons example](./assets/no-slop-icons.png)

Lucide icons are a common vibe-coding default that makes interfaces look AI-generated.

## How it works

Detects Lucide package imports and rendered Lucide class or data attributes.

## How to fix

Use a product-specific icon set, authored SVGs, or native platform symbols with consistent stroke and optical sizing.

## Common false positives

A product with an established Lucide-based design system may prefer consistency over replacing the library.
