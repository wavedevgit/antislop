# Text arrow

![Text arrow example](./assets/no-text-arrows.png)

Only AI uses this arrow. Use an icon instead.

## How it works

Finds arrow characters used directly in interface copy.

## How to fix

Replace the character with an accessible icon component, or remove it when the label already communicates direction.

## Common false positives

Code samples, mathematical notation, and user-authored content may contain arrow characters literally.
