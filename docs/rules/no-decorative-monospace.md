# Monospace font

![Monospace font example](./assets/no-decorative-monospace.png)

Only use monospace for syntax-highlighted code, not single-color labels, prose, or decorative text.

## How it works

Reports single-color monospace text while allowing multi-color syntax-highlighted code and inline code tokens.

## How to fix

Use the interface or body typeface for labels and prose. Reserve monospace for code, identifiers, and aligned technical data.

## Common false positives

Terminal output, file paths, measurements, and identifiers are legitimate monospace content.
