# Monospace font

![Monospace font example](./assets/no-decorative-monospace.png)

Only use monospace for syntax-highlighted code, not single-color labels, prose, or decorative text.

## How it works

Reports single-color monospace text while allowing multi-color syntax-highlighted code.
