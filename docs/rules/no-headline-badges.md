# Headline badge

![Headline badge example](./assets/no-headline-badges.png)

AI-generated landing pages often place a decorative pill badge directly above the main headline.

## How it works

Detects a pill-shaped badge placed directly above the main page heading.

## How to fix

Remove the decorative badge and put useful context in the headline or supporting copy.

## Common false positives

A real status, release channel, or time-sensitive announcement may belong near the headline.
