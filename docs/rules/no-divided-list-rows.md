# Divided list rows

![Divided list rows example](./assets/no-divided-list-rows.png)

AI-generated sites often present ordinary content as repeated multi-column rows separated by horizontal rules.

## How it works

Finds repeated multi-column content rows separated by horizontal rules.

## How to fix

Use a semantic list, table, or simpler grouped layout. Remove repeated columns or separators that do not help comparison.

## Common false positives

Real data tables, schedules, and comparison lists may require columns and row separators.
