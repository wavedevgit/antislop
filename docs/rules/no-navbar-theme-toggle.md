# Navbar theme switcher

![Navbar theme switcher example](./assets/no-navbar-theme-toggle.png)

Navbar theme toggles are an AI-generated website trope that people rarely use.

## How it works

Finds visible theme, dark-mode, or light-mode controls inside navbars and headers.

## How to fix

Remove the control unless users need it. Prefer the system color scheme or place appearance settings with other preferences.

## Common false positives

Reading tools, accessibility-focused products, and applications used for long sessions may benefit from an explicit theme control.
